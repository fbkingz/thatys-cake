# Thaty's Cake

Site estático da Thaty's Cake, pronto para abrir e testar no Visual Studio Code.

## Abrir no VS Code

1. Abra o Visual Studio Code.
2. Clique em **File > Open Folder**.
3. Selecione a pasta deste projeto: `thatys-cake`.
4. Abra o terminal pelo menu **Terminal > New Terminal**.
5. Execute `npm start`.
6. Abra no navegador o endereço mostrado, normalmente `http://localhost:3000`.

## Testar arquivos essenciais

No terminal, execute:

```bash
npm test
```

## Estrutura

- `public/index.html`: página do site.
- `public/assets/`: fotos, favicon e demais imagens.
- `serve.mjs`: servidor local para a prévia.
- `check.mjs`: verificação simples dos arquivos essenciais.

Não é necessário instalar bibliotecas para usar os comandos acima: basta ter o Node.js instalado no computador.
